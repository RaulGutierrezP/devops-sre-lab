# DevOps / SRE Professional Lab

Laboratorio práctico para aprender y aplicar prácticas profesionales de DevOps y SRE.

## Objetivo

Construir y operar una aplicación pequeña mediante un flujo profesional de:

Git → GitHub → CI → Docker → Registry → CD → ECS/Floc.io → Observabilidad → SRE

El proyecto prioriza:

- Automatización
- Reproducibilidad
- Seguridad
- Observabilidad
- Fiabilidad
- Mejora continua
